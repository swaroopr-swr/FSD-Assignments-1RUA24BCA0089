## 📌 Project Overview

**BCA Web Clone** is a frontend web application designed to replicate the UI/UX, layouts, and interaction patterns of a modern web platform. The goal of this project is to demonstrate mastery of modern web technologies, responsive layouts, modular component design, and responsive design systems.

### Key Objectives
- Recreate modern responsive web pages with pixel-accurate layout and styling.
- Implement mobile-first, responsive grid and flexbox architectures.
- Ensure semantic HTML, accessibility (a11y), and fast load times.
- Practice component-driven design and structured project organization.

---

## 🚀 Features

- **Responsive Navigation:** Mobile drawer / hamburger menu and desktop navigation bar.
- **Hero & Content Sections:** Clean visual hierarchy, modern typography, and structured content layouts.
- **Component Reusability:** Modular cards, buttons, banners, and layout containers.
- **Form Controls & Inputs:** Accessible input fields with validation states.
- **Cross-Browser Compatibility:** Consistent appearance and behavior across Chrome, Safari, Firefox, and Edge.

## 🏃 Getting Started

### Prerequisites
- Any modern web browser (Google Chrome, Firefox, Safari, Edge)
- Optional: VS Code with the *Live Server* extension or Node.js (`npx serve`)

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/swaroopr-swr/FSD-Assignments-1RUA24BCA0089.git
   cd "FSD-Assignments-1RUA24BCA0089/BCA WEB CLONE"
   ```
2. Open with Live Server or run:
   ```bash
   # Using Python
   python3 -m http.server 3000

   # Or using npx serve
   npx serve .
   ```
3. Open `http://localhost:3000` in your web browser.
